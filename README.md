# Control de Horas Semanales en Python

Programa desarrollado en Python para calcular las horas trabajadas por un equipo durante la semana y clasificar si existe sobretiempo.

## Funcionalidades
- Uso de matrices
- Funciones en Python
- Cálculo de horas semanales
- Clasificación de jornada laboral
